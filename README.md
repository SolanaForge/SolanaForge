# SolanaForge – No-Code SPL Token Creator on Solana

SolanaForge is a non-custodial **no-code SPL token creation platform on Solana** that allows users to create and deploy tokens in minutes without writing smart contracts.

🌐 Website: https://solanaforge.app

---

## 💡 What is SolanaForge?

SolanaForge is a **Solana token creator** that enables anyone to launch SPL tokens without coding.

It simplifies the process of creating tokens on the Solana blockchain by providing a transparent, beginner-friendly interface for deployment.

---

## 🚀 Create a Solana Token in Minutes

With SolanaForge, users can:

- Create SPL tokens instantly
- Deploy tokens on Solana without coding
- Simulate transactions before signing
- Manage token authority settings
- Launch memecoins or utility tokens easily

## 🔐 Security Principles

SolanaForge is built on a non-custodial architecture:

- Users always control their wallets
- All transactions require explicit approval
- No private keys or seed phrases are ever requested
- Transparent fee and transaction simulation before signing

SolanaForge will NEVER request:
- Private keys
- Seed phrases
- Wallet recovery phrases
