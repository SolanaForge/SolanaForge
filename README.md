# SolanaForge

SolanaForge is a non-custodial Solana platform for transparent SPL token creation.

The platform is designed to provide beginner-friendly token deployment tools with transparent wallet interactions, transaction simulations, and educational onboarding.

---

## Features

- SPL token creation
- Transparent transaction previews
- Fee estimation and simulation
- Optional authority revocation
- Metadata support
- Phantom-compatible wallet flow
- Non-custodial architecture
- Beginner-friendly onboarding

---

## Security Principles

SolanaForge is designed around:
- transparent wallet interactions
- visible fee breakdowns
- user-controlled signatures
- non-custodial architecture
- educational safety guidance

SolanaForge will NEVER request:
- private keys
- seed phrases
- wallet recovery phrases

All blockchain actions require explicit wallet approval from the user.
