# SolanaForge Roadmap

## Vision

SolanaForge aims to provide a transparent, beginner-friendly, and security-conscious platform for Solana SPL token creation.

The platform focuses on:
- non-custodial architecture
- transparent wallet interactions
- educational onboarding
- professional token deployment workflows

---

# Phase 1 — Foundation

Completed or in progress:

- Public website launch
- SPL token creation workflow
- Phantom wallet integration
- Transparent transaction simulations
- Fee estimation system
- Authority revoke support
- Security documentation
- Public GitHub repository
- Community platform setup
- SEO and transparency improvements

# Core Principles

SolanaForge aims to remain focused on:

- non-custodial architecture
- transparent wallet interactions
- educational onboarding
- visible fee transparency
- security-conscious design
- user-controlled approvals

---

# Security Reminder

SolanaForge will NEVER request:
- private keys
- seed phrases
- wallet recovery phrases

Users should always verify wallet prompts carefully before signing transactions.
