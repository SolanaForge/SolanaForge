# Fee Breakdown Guide

## Understanding SolanaForge Token Creation Costs

SolanaForge provides transparent fee estimation before users approve transactions.

All displayed fees are shown before wallet confirmation.

---

## Estimated Fees May Include

### Mint Account Rent

Required by the Solana blockchain to create the token mint account.

Example:
- ~0.0015 SOL

---

### Metadata Account

Required for storing token metadata such as:
- token name
- symbol
- image/logo
- description

Example:
- ~0.0056 SOL

---

### Token Account (ATA)

Associated Token Account creation cost.

This allows wallets to properly hold and manage the created token.

Example:
- ~0.00204 SOL

---

### Solana Network Transaction Fee

Standard Solana blockchain transaction cost.

Example:
- ~0.00001 SOL

---

### Platform Service Fee

Platform fee for SolanaForge infrastructure, maintenance, transaction orchestration, and token deployment services.

Example:
- 0.1 SOL

---

### Safety Buffer

Small estimation buffer for blockchain variability and transaction reliability.

Example:
- ~0.001 SOL

---

## Transaction Simulation

Before signing, SolanaForge may display:
- estimated fees
- revoke settings
- token settings
- total estimated costs

Simulation does not execute blockchain transactions.

No wallet signatures occur during simulation.

---

## Transparency Principles

SolanaForge is designed with:
- transparent wallet interactions
- visible fee breakdowns
- user-controlled approvals
- non-custodial architecture

Users always review transactions directly inside their wallet before approval.

---

## Security Reminder

Always verify:
- wallet prompts
- transaction details
- estimated costs
before signing any blockchain transaction.

SolanaForge will NEVER request:
- private keys
- seed phrases
- wallet recovery phrases
