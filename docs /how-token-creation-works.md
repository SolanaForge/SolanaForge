# How Solana Token Creation Works

## Introduction

SolanaForge helps users create SPL tokens on the Solana blockchain through a transparent non-custodial workflow.

Users maintain full control of their wallets throughout the process.

---

## Step 1 — Connect Wallet

Users connect a compatible Solana wallet such as:
- Phantom
- Solflare
- other compatible wallets

Wallet connections are always:
- user-initiated
- transparent
- confirmed directly inside the wallet

SolanaForge never requests:
- seed phrases
- private keys
- wallet recovery phrases

---

## Step 2 — Configure Token Settings

Users may configure:
- token name
- token symbol
- supply
- decimals
- logo/image
- description
- authority settings

Optional revoke settings may include:
- mint authority
- freeze authority
- update authority

---

## Step 3 — Transaction Simulation

Before signing, SolanaForge may display:
- estimated network fees
- metadata costs
- account rent costs
- platform service fees
- revoke settings
- estimated total cost

Simulation does not execute blockchain transactions.

No wallet signatures occur during simulation.

---

## Step 4 — Review Transaction

Users review transaction details directly inside their wallet before approval.

This may include:
- token configuration
- estimated costs
- authority selections
- transaction instructions

All blockchain actions require explicit wallet approval.

---

## Step 5 — Token Deployment

After wallet confirmation:
- the SPL token is created on-chain
- metadata is registered
- authorities are configured based on user selections

Users maintain full ownership and control of their wallets throughout the process.

---

## Non-Custodial Architecture

SolanaForge is designed as a non-custodial platform.

This means:
- users control their wallets
- users approve transactions directly
- SolanaForge does not hold user funds

---

## Security Principles

SolanaForge emphasizes:
- transparent wallet interactions
- visible fee breakdowns
- no hidden approvals
- educational onboarding
- user-controlled signatures

---

## Beginner Reminder

Before signing transactions:
- verify wallet prompts carefully
- review revoke settings
- understand estimated costs
- use official SolanaForge links only
